# Emo Store V10 Final Contact

مشروع متجر إلكتروني تعليمي كامل Frontend + Backend + API + Dashboard.

## التشغيل

```bash
cd emo-store-v10-final-contact
npm start
```

افتح:

```text
http://localhost:5000
```

## الصفحات

```text
Home:
http://localhost:5000

Products:
http://localhost:5000/products.html

Login:
http://localhost:5000/login.html

Dashboard:
http://localhost:5000/dashboard.html
```

## الجديد

- ضبط كروت Shop by Category بنفس المستوى باستخدام Flex ثابت.
- عند الضغط على Contact Us يظهر Popup فيه الرقم.
- إضافة خانة Contact جديدة في صفحة Home.
- الصفحات كلها متربطة ببعض.
- Backend API كامل.
- Dashboard لإضافة وتعديل وحذف المنتجات.
- Cart + WhatsApp Checkout.
